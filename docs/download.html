Get started with Varve

Three tools: a wallet to hold and send coins, an explorer to look things up, and the node to run and mine the network. Everything is free and open source, and it is all testnet software for now: testnet coins have no value.

  • Wallet

    Strata

    For holding and sending VARV. Strata is the Varve desktop wallet. It runs on your own computer and opens in your browser. Create a wallet or restore one from your 24-word recovery phrase, see your balance and history, and send or receive coins. Your keys are generated and stored on your computer only, in a wallet file encrypted with your passphrase.

    Download for Windows, macOS or Linux

    How to install
    1. Open the releases page and download the file for your system: …-windows-x86_64.zip, …-macos-arm64.tar.gz (Apple Silicon) or …-linux-x86_64.tar.gz.
    2. Check the download against SHA256SUMS on the same page.
    3. Unpack it and start strata (strata.exe on Windows). It opens in your browser.
    4. Create a wallet, write the 24 words down on paper, and keep them somewhere safe. Anyone with those words can take your coins, and without them a lost computer means lost coins.

    Builds are not yet code-signed, so Windows and macOS may warn that the app is from an unknown developer. Only download from the official releases page.

  • Block explorer

    Varvescan

    For looking things up. Varvescan shows everything on the Varve blockchain: the latest blocks, any transaction, and any address with its balance, history and where its coins came from. Use it to check that a payment arrived. Nothing to install, it runs in your browser and uses no cookies or trackers.

    Open Varvescan

    Testnet data appears as soon as the first public node is online. Mainnet has not launched.

  • Node and miner

    Varve node

    For running and mining the network. The Varve node checks every block and transaction itself and helps keep the network alive. It also mines VARV on an ordinary computer's processor; no special hardware is needed. Run it on your own computer or on a server.

    Download the nodeSetup guide

    Quick start
    1. Download and unpack the file for your system from the releases page (the same download as Strata; both programs are included).
    2. Copy a receiving address from Strata, then start mining to it: varve node --mine --mine-to tvarve1…. The node then holds no keys at all.
    3. Or give the node its own encrypted wallet first: varve wallet create (it shows 24 words once; write them down), then varve node --mine.
    4. Check progress: varve rpc getmininginfo. Mined coins can be spent after 288 blocks, about a day.

    Mining in the fastest mode needs about 2.1 GB of free memory; add --light on small machines. To run a public server node, see the setup guide.

The first testnet release appears on the releases page when the first public seed node goes online. Until then you can build everything from source; see the setup guide.
