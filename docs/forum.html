Community guidelines

  • Keep discussion technical: the specification, security, implementation and review.
  • No price talk, shilling or giveaways. No coin exists, so there is nothing to price.
  • Never share seeds or private keys, with anyone, for any reason.
  • The developers will never DM you first. Treat any unsolicited message claiming to be from them as a scam.

Later

A self-hosted, community-run forum may be added later. If it is, it will be announced only via signed repository commits. Do not trust any other announcement.
