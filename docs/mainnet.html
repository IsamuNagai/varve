Mainnet readiness

What has to be true before mainnet

Mainnet launches when every item below is done, not on a date. This page separates what is proven from what is only designed.

Designed versus proven

Some of Varve is designed and has passed serious testing: the consensus rules, three implementations that agree on them, and the battle tests. Some is designed but not yet proven in the wild: how the network behaves with thousands of strangers, real miners and real attackers. That proof can only come from a long public testnet and independent reviewers. Items move to "Done" only with evidence you can check.

Protocol and code

  • Done
    Every consensus rule specified in public documents

    Draft v0.5 in protocol/. The rules are frozen before mainnet; changes until then are public, with decision records.

  • Done
    Three implementations agree on every test vector

    A reference prototype, an independent verifier written only from the specification, and the Rust node.

  • Done
    Battle tests: consensus attacks, chain rewrites, corrupted data, power cuts

    The first run found two bugs, both fixed; the second run passed all 55 tests. Results and charts.

  • Not started
    Network-flood and connection-exhaustion testing

    How a node holds up when peers flood it with connections and messages, tested under controlled conditions.

  • Not started
    Continuous fuzzing

    Long-running fuzzers for every parser and message type, not only the one-off fuzzing in the battle tests.

  • Not started
    Independent human security audit of the node

    A public, named review. So far there has been an independent human review of the protocol and an AI-assisted review of the code.

  • Not started
    Expert review of the proof of work

    RandomX v2 with Varve's salt, reviewed by people who know RandomX.

  • Not started
    A second, independent full node

    Written by different people, so that one implementation's bug cannot become the network's rule.

Network

  • In progress
    Public testnet with seed nodes

    The node, miner, wallet and explorer are ready; the first public seed node is being prepared.

  • Not started
    Months of public testnet with outside miners

    Including deliberate stress, chain splits and a rehearsal of a signature-scheme upgrade.

  • Not started
    Seed nodes run by several independent operators

Releases and wallets

  • In progress
    Release builds from tagged source, with checksums

    Built by GitHub Actions for Linux and macOS (x86-64 and ARM). Windows builds are being added.

  • Done
    Strata wallet with an encrypted wallet file and a 24-word recovery phrase

    Runs on your own computer; keys never leave it.

  • Done
    Varvescan block explorer

    Ready, and live once the testnet is.

  • Not started
    Reproducible builds

    Anyone can rebuild a release and get identical files.

  • Not started
    Several independent release signers

Launch

  • Not started
    Bitcoin anchor heights announced well in advance

    Mainnet's genesis is derived from six future Bitcoin blocks, so nobody can mine early. The heights are published before they exist.
